## 3. Sette Innovazioni Implementate

### (1) Structural Permission Enforcement
`tools` allowlist su agent reviewer2.md. R2 ora ha `tools: Read, Grep, Glob, WebSearch, WebFetch`. Strutturalmente NON PUÒ usare Write, Edit, Bash. Il Permission Model diventa architetturale.

### (2) Dynamic Context Injection
`!` prefix nei comandi `/start` e `/loop`. Pre-inietta STATE.md, CLAIM-LEDGER status, PROGRESS.md e TREE-STATE.json nel contesto PRIMA che Claude inizi a pensare. Elimina un round-trip di Read tool.

### (3) PreToolUse Hook (LAW 9)
Hook che intercetta il Write tool PRIMA dell'esecuzione. Blocca scritture su CLAIM-LEDGER senza campo `confounder_status`. Regex flessibile con escape NOT_APPLICABLE.

### (4) SubagentStop Hook (Salvagente Rule)
Hook che verifica quando un subagente finisce: se ci sono claim KILLED nella sessione corrente, controlla nel DB che ogni claim abbia un serendipity seed. Blocca se la Salvagente Rule è violata.

### (5) Command Scoping
`model` e `allowed-tools` per ogni comando. `/search` usa `model: sonnet` (workload retrieval-heavy). `/reviewer2` ha tools read-only.

### (6) Environment Variables
`MCP_TIMEOUT=30000`, `MAX_MCP_OUTPUT_TOKENS=100000`, `CLAUDE_BASH_MAINTAIN_PROJECT_WORKING_DIR=1`. Aggiunte a `.claude/settings.json`.

### (7) Spec-Compliant Frontmatter
Solo campi ufficiali. SKILL.md trimmed a 3 campi (name, description, allowed-tools). Agent reviewer2 a 4 campi. Comandi con argument-hint al posto di args.

## 5. Rischi e Mitigazioni

| Rischio | Mitigazione |
|---------|-------------|
| PreToolUse blocca scritture legittime | Regex flessibile: accetta `confounder_status:` o `confounder.*not.?applicable` |
| SubagentStop blocca senza DB | Graceful degradation: se DB non disponibile, exit 0 (allow) |
| Campi non-standard rotti | Audit paranoico: zero occorrenze di `capabilities:` nei frontmatter agent |

## 6. Principio Architetturale

> **v6.0 ha separato Skill da Plugin (mente vs corpo). v6.0.1 rende il corpo più forte — structural permissions, pre-action hooks, environment hardening — senza toccare la mente.**
